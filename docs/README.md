# Documentation Perim'APP

Ce dossier contient la documentation complète du projet Perim'APP.

## 📁 Structure de la documentation

### 📄 [Spécifications Fonctionnelles](specifications-fonctionnelles.md)
Document décrivant **QUOI** fait l'application du point de vue utilisateur :
- Vue d'ensemble et objectifs du projet
- Personas utilisateurs et cas d'usage
- Exigences fonctionnelles détaillées
- Spécifications de l'interface utilisateur
- Règles métier et roadmap

**Public cible :** Product Owners, Business Analysts, UX/UI Designers, Testeurs

### 🔧 [Spécifications Techniques](specifications-techniques.md)
Document décrivant **COMMENT** l'application est construite du point de vue technique :
- Architecture système et application
- Stack technique et technologies utilisées
- Base de données et intégrations API
- Sécurité, déploiement et environnement
- Tests, performance et monitoring

**Public cible :** Développeurs, Architectes, DevOps, Lead Tech

## 🎯 Objectif

Ces documents servent de référence complète pour :
- ✅ Comprendre les besoins fonctionnels et techniques
- ✅ Onboarder de nouveaux membres de l'équipe
- ✅ Maintenir la cohérence du développement
- ✅ Documenter les décisions architecturales
- ✅ Faciliter la maintenance et les évolutions

## 📝 Mise à jour

Ces documents sont **vivants** et doivent être mis à jour lors de :
- Ajout de nouvelles fonctionnalités
- Changements architecturaux
- Évolutions des technologies
- Modifications des exigences métier
