Flux de données principal :
==========================

1. Utilisateur → Interface XAML (MainPage)
2. Interface → Service (NeonProductService)
3. Service → Base de données PostgreSQL
4. Données ← Service ← Base de données
5. Interface ← Modèle (ProductInfos) ← Service
6. Affichage produits avec calculs de péremption

Technologies utilisées :
========================

Frontend:    .NET MAUI 9.0, XAML, C#
Backend:     Services C#, Npgsql
Database:    PostgreSQL (Neon Cloud)
Security:    Argon2 Password Hashing
Testing:     xUnit, 35 tests unitaires
CI/CD:       GitHub Actions
